# 🍱 Intelligent Food Delivery Quality Checker

> An AI-powered web application that evaluates food delivery quality using image analysis and customer complaint prediction.

---

## ✨ About The Project

The **Intelligent Food Delivery Quality Checker** is a smart quality analysis system developed using **Machine Learning, Deep Learning, and NLP** technologies.  

This application analyzes uploaded food images using a **TensorFlow CNN model** and evaluates customer complaints using **Natural Language Processing (NLP)** techniques. Based on both predictions, the system generates an overall food delivery quality score with visual insights.

---

🌟 Food Image Quality Detection
